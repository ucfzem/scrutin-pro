# Scrutin Pro
Système de vote et dépouillement en direct.

## Utilisation
Ouvrez `index.html` dans un navigateur. Configurez le scrutin, ajoutez les candidats, puis lancez le vote.

## Fonctionnalités
- Vote en direct avec dépouillement en temps réel
- Grille d'émargement (PV)
- Bilingue français/arabe (RTL natif)
- Export PDF / impression du PV
- 100% mobile-first, données en localStorage
